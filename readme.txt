FastROM Plus brings many QoL improvements all around for the vanilla game. Complete list of changes:

  - Improves game performance
  - Implements the EXTRA OPTIONS menu with the following toggles:
      - D-TAP DASH (OFF by default, toggles double-tap dash)
      - BETTER SUB-TANK (ON by default, stops sub-tanks from depleting once health is full)
  - Adds SRAM saving for in-game passwords, control scheme, and option toggles
  - Exiting OPTION MODE now goes back directly to the main menu, instead of restarting the intro
  - Implements an EXIT button in the PASS WORD screen, so you can go back to the main menu from there
  - Assigns dash to L by default
  - Dialogue boxes open, close, and scroll faster
  - Pressing START skips the boss intro
  - Compatible with the MSU-1 and Relocalization Addendum patches

Apply "fastrom_plus.ips" to your USA ROM. If you're using bsnes/ares you also need the manifest "fastrom_plus.bml" in the same folder and with the same name as your base ROM.

If you're using the MSU-1 patch: Apply "fastrom_plus.ips" first, then apply everything the MSU-1 patch needs. If you're using bsnes/ares, DON'T use the manifest that comes with MSU-1, use "fastrom_plus.bml" instead, then follow the instructions of the MSU-1 patch.

The Relocalization Addendum patch can be applied at any point.
